## Software

We help build software for the scientific community.
Our software is openly developed on GitHub under both the [pyTMD](https://github.com/pyTMD) and [polargeodesy](https://github.com/polargeodesy) organizations, as well as the individual accounts of [team members](../people/index.html).

### pyTMD
Python-based tidal prediction software for ocean and Earth tides  
[GitHub](https://github.com/pyTMD/pyTMD) &middot;
[Documentation](https://pyTMD.readthedocs.io) &middot;
[JOSS](https://doi.org/10.21105/joss.08566) &middot;
[PyPI](https://pypi.python.org/pypi/pyTMD/) &middot;
[conda-forge](https://anaconda.org/conda-forge/pytmd)

### gravity-toolkit
Python tools for working with time-variable gravity fields from GRACE and GRACE Follow-On  
[GitHub](https://github.com/polargeodesy/gravity-toolkit) &middot;
[Documentation](https://gravity-toolkit.readthedocs.io) &middot;
[PyPI](https://pypi.python.org/pypi/gravity-toolkit/) &middot;
[conda-forge](https://anaconda.org/conda-forge/gravity-toolkit)

### model-harmonics
Python tools for working with spherical harmonic coefficients derived from atmospheric, oceanic, and land surface models  
[GitHub](https://github.com/polargeodesy/model-harmonics) &middot;
[Documentation](https://model-harmonics.readthedocs.io) &middot;
[PyPI](https://pypi.python.org/pypi/model-harmonics/) &middot;
[conda-forge](https://anaconda.org/conda-forge/model-harmonics)


### geoid-toolkit
Python-based geoid and gravity calculation software for geophysics and geodesy applications  
[GitHub](https://github.com/polargeodesy/geoid-toolkit) &middot;
[Documentation](https://geoid-toolkit.readthedocs.io) &middot;
[PyPI](https://pypi.python.org/pypi/geoid-toolkit/) &middot;
[conda-forge](https://anaconda.org/conda-forge/geoid-toolkit)

### IS2view
Interactive visualization and data extraction tool for ICESat-2 ATL14/ATL15 gridded land ice height products  
[GitHub](https://github.com/tsutterley/IS2view) &middot;
[Documentation](https://IS2view.readthedocs.io) &middot;
[PyPI](https://pypi.python.org/pypi/IS2view/) &middot;
[conda-forge](https://anaconda.org/conda-forge/is2view)

### FirnCorr
Python-based tools for correcting data for surface mass balance and firn processes  
[GitHub](https://github.com/tsutterley/FirnCorr) &middot;
[Documentation](https://FirnCorr.readthedocs.io) &middot;
[PyPI](https://pypi.python.org/pypi/FirnCorr/)

### IceAdvect
Utilities for advecting point data for use in a Lagrangian reference frame  
[GitHub](https://github.com/tsutterley/IceAdvect) &middot;
[Documentation](https://IceAdvect.readthedocs.io)
